Como preparar o projeto

  • Requisitos: um arquivo cujo nome contenha "requisito" ou "requirement" (requisitos.md, .csv ou .json), com identificadores como RF-01.
  • Linguagens: Python, Java, JavaScript e HTML (elementos de interface com id).
  • Testes: pytest/unittest (test_*.py), JUnit (*Test.java, métodos com @Test) e JavaScript (*.test.js ou *.spec.js, com test() ou it()).
  • Marcação explícita (opcional): cite o requisito em comentários, docstrings ou no nome do teste, por exemplo # @traces RF-01 ou test_rf01_login.
  • Arquivos sensíveis (.env, chaves, credenciais) são ignorados automaticamente.
